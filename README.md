### What I Work On

I focus on the engineering layer where AI agents meet real software systems: codebases, mobile runtimes, developer workflows, and production rendering pipelines.

- **AI Agents**: agent runtime, tool orchestration, codebase collaboration, and CLI-first automation.
- **Android Engineering**: runtime debugging, app introspection, performance analysis, and developer tooling.
- **Cross-platform Rendering**: DSL-driven UI, rendering engines, protocol design, and multi-end consistency.
- **Developer Experience**: small tools that turn complex engineering workflows into repeatable commands.
